Endpoints

            
Every endpoint is a GET request that returns JSON. Paths are relative to the
                host above.

            

        


        

            
Good to know

            

                

                    
Matching

                    
    
                        
  • Country codes are case-insensitive: /v1/countries/mm works.
    • 
                        
  • State names are forgiving: exact match first, then starts-with, then contains.
                            /states/yangon/cities finds Yangon Region.
    • 
                        
  • Search is a case-insensitive substring match. City search also matches
                            name_local, such as Myanmar script.
    • 
                    

                

                

                    
Limits

                    
    
                        
  • Search returns at most 20 countries, 20 states, 50 cities or 10 phone-code matches.
    • 
                        
  • Cities come back in the source data's order, not ranked by relevance.
    • 
                        
  • No API key or sign-up needed.
    • 
                    

                

                

                    
Errors

                    
    
                        
  • 404 with a JSON detail, for example
                            "Country not found", "State not found" or
                            "Region not found".
    • 
                        
  • 400 for a malformed URL, and 405 for any method other than GET or
                            HEAD.
    • 
                    

                

                

                    
Caching & CORS

                    
    
                        
  • Responses carry Cache-Control: public, max-age=3600 and an ETag, so browsers
                            can revalidate cheaply.
    • 
                        
  • Any origin can call the API from the browser, preflight included.
    • 
                    

                

            

        


        

            
Example: country → state → city dropdowns

            
Plain fetch, no client library needed.

            
const API = 'https://country-api.drnyeinchan.com/v1';

// 1. Countries for the first dropdown
const countries = await fetch(`${API}/countries`).then((r) => r.json());
// [{ code: 'AF', name: 'Afghanistan', phone_code: '+93', flag: '🇦🇫' }, …]

// 2. States once a country is picked
const states = await fetch(`${API}/countries/MM/states`).then((r) => r.json());

// 3. Cities once a state is picked (encode names that contain spaces)
const cities = await fetch(
  `${API}/countries/MM/states/${encodeURIComponent('Yangon Region')}/cities`
).then((r) => r.json());
